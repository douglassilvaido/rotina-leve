PUBLICAÇÃO NA VERCEL
1. Descompacte o ZIP.
2. Importe a pasta ROTINA_LEVE_SITE_VERCEL em um repositório GitHub.
3. Na Vercel: Add New > Project > Import Git Repository.
4. Framework Preset: Other; Root Directory: ./; sem comando de build.
5. Clique Deploy. Abra a URL fornecida pela Vercel.
6. Teste todas as nove imagens e os botões de compra no celular.
